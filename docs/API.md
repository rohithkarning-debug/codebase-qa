# Web API

Base URL: `http://127.0.0.1:8000`. Interactive docs: `/docs` (Swagger UI, generated by FastAPI).

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/health` | Liveness check |
| GET | `/api/config` | Active LLM, embedding models, chunkers, retrievers, defaults |
| GET | `/api/repos` | Repositories with clone status and built indexes |
| POST | `/api/repos` | Add a GitHub repo `{url, ref?, name?}`; returns a background job |
| POST | `/api/repos/{name}/index?embedders=code,general` | (Re)build all indexes for a repo; returns a job |
| GET | `/api/jobs/{id}` | Job progress `{status, stage, done, total, message}` |
| GET | `/api/repos/{name}/files` | Indexed source files |
| GET | `/api/repos/{name}/file?path=` | File content for the code viewer (403 for paths outside the repo) |
| GET | `/api/repos/{name}/search?q=&chunker=&retriever=&k=` | Retrieved chunks with scores and GitHub links |
| GET | `/api/repos/{name}/compare?q=&k=` | Same query against all 8 chunker x retriever indexes; marks correct chunks for test-set questions |
| POST | `/api/ask` | Answer a question, streamed as NDJSON (see below) |
| GET | `/api/eval/questions?repo=` | The test-set questions |
| GET | `/api/eval/results` | Contents of `results/retrieval.json` and `results/answers.json` |

## Streaming answers

```http
POST /api/ask
{"repo": "requests", "question": "Where is HTTP Basic authentication handled?",
 "mode": "agent", "chunker": "ast", "retriever": "code"}
```

Response (`application/x-ndjson`), one JSON object per line:

```json
{"type": "start", "question": "...", "repo": "requests", "llm": "gemini:gemini-flash-latest"}
{"type": "step", "step": 1, "thought": "...", "action": "search_code", "input": {"query": "..."},
 "observation": "1. src/requests/auth.py:L76-L96 ...", "locations": [{"path": "...", "start": 76, "end": 96}]}
{"type": "step", "step": 2, "action": "open_file", ...}
{"type": "answer", "answer": "... [src/requests/auth.py:L76-L96] ...",
 "citations": [{"path": "src/requests/auth.py", "start": 76, "end": 96, "valid": true,
                "url": "https://github.com/psf/requests/blob/0e322af.../src/requests/auth.py#L76-L96"}],
 "steps": 3, "seconds": 4.2, "llm": "..."}
```

Errors arrive as `{"type": "error", "message": "..."}`. `mode: "rag"` sends `start` and `answer` only (the answer
also carries the retrieved `hits`).

## Example

```bash
curl -N -X POST localhost:8000/api/ask -H 'Content-Type: application/json' \
  -d '{"repo":"starlette","question":"Where is authentication handled?"}'
```
